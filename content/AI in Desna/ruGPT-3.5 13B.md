#### **Краткое описание:**  
ruGPT-3.5 13B — это крупная языковая модель, разработанная ai-forever, специально для русского языка, с 13 млрд параметров. Она используется для генерации текста и была основой для обучения GigaChat.

#### **Ключевые особенности:**

- **Обширные тренировочные данные:** Обучена на 300 ГБ данных различных доменов, плюс дополнительные 100 ГБ кода и юридических документов, обеспечивая широкий охват знаний.
- **Высокая производительность генерации текста:** Способна генерировать плавный и связный русский текст, подходящий для чат-ботов и диалоговых агентов.
- **Открытый доступ:** Доступна на Hugging Face, с квантованными версиями для эффективного развертывания.

#### **Минимальные требования без GPU:**

|Компонент|Минимальные требования|Комментарии|
|---|---|---|
|CPU|Высокопроизводительный многоядерный CPU|Требуется для обработки вычислений, скорость зависит от количества ядер.|
|RAM|64 ГБ|Необходимы для работы с моделью такого размера.|
|Хранилище|SSD с минимум 100 ГБ свободного места|Необходим для хранения модели и данных, предпочтительно быстрый SSD.|

#### **Минимальные требования с GPU:**

- **GPU:** Минимум 20 ГБ VRAM для эффективного вывода.
- **CPU:** 8-ядерный процессор.
- **RAM:** 64 ГБ для стабильной работы.
- **Хранилище:** 100 ГБ SSD.

#### **Техническая реализация:**

- **Серверная часть:** Модель можно загрузить и запустить с помощью библиотек, таких как Transformers, с поддержкой квантования для оптимизации.
- **Клиентская часть:** Интеграция с веб-интерфейсами или мессенджерами для взаимодействия с гостями.
- **Сеть:** Локальное развертывание с использованием REST API для запросов и ответов.
- **План обучения:** Подготовить данные (100-500 пар вопрос-ответ), дообучить модель на специфических данных комплекса, протестировать точность ответов и развернуть.

#### Техническая реализация и интеграция

Для обеих моделей предполагается использование сервера на базе Ubuntu с возможностью запуска на GPU (если доступно) или оптимизированного для CPU. Развертывание может быть организовано через LLM-сервер, например, с использованием FastAPI и Langchain/LLama.cpp. Автоматический запуск бота при старте системы обеспечит непрерывность работы.

Данные оздоровительного комплекса (сайт, расписание, внутренние регламенты, FAQ) будут интегрированы через базы данных (PostgreSQL/MySQL) или локальные файлы (.json/.csv), с периодической синхронизацией для актуальности. Использование RAG позволит боту искать информацию в документах, повышая точность ответов.

#### Взаимодействие с пользователями

Чат-бот может быть интегрирован через интерфейсы, такие как веб-чат или, при желании, голосовой помощник. Логирование и анализ запросов гостей обеспечат возможность дальнейшего улучшения бота, что важно для повышения удовлетворенности пользователей.
