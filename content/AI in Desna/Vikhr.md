### **Краткое описание:**

Vikhr — это передовая открытая инструкционная модель, настроенная для русского языка, основанная на архитектуре Mistral. Она разработана для эффективной генерации и обработки текстов на русском, с акцентом на диалоговые задачи.

**Ключевые особенности:**

- **Адаптированный токенизатор:** Включает словарь, оптимизированный для русского языка, что улучшает представление и понимание текста.
- **Продолженное предобучение и настройка:** Модель проходит дополнительное предобучение и инструкционную настройку всех весов, что повышает ее производительность и контекстную эффективность для русского.
- **Двуязычная поддержка:** Подходит для работы с русским и английским, что делает ее универсальной для мультиязычных приложений.
- **Производительность:** Устанавливает новый стандарт среди открытых моделей для русского языка, превосходя некоторые проприетарные закрытые модели в определенных бенчмарках.

### **Системные требования:**

Для стандартной версии Vikhr (7 млрд параметров) требуется:

|Компонент|Минимальные требования|Комментарии|
|---|---|---|
|GPU|Минимум 12 ГБ VRAM, с возможностью квантования|Рекомендуется 16 ГБ для стабильности.|
|CPU|Современный многоядерный CPU|Требуется для обработки вычислений.|
|RAM|32 ГБ|Достаточно для квантованной модели.|
|Хранилище|SSD с минимум 50 ГБ свободного места|Для хранения модели и данных.|

С оптимизацией GGUF (например, файлы около 2-3 ГБ, как Q4_K_M) модель можно запустить на GPU с 8 ГБ VRAM, что делает ее доступной для ограниченного оборудования.

### **Техническая реализация:**  
Модель можно запустить с помощью инструментов, таких как Hugging Face Transformers, обеспечивающих API для взаимодействия. С GGUF-версиями рекомендуется использовать llama.cpp для локального инференса. Веб-интерфейс может быть реализован через OpenWebUI, подключающийся к серверу через API.

### **Минимальные требования с GPU:**

- **GPU:** Минимум 12 ГБ VRAM, с возможностью квантования.
- **CPU:** 8-ядерный процессор.
- **RAM:** 16 ГБ (может быть недостаточно для сложных задач).
- **Хранилище:** 50 ГБ SSD.

### **Рекомендуемые требования с GPU:**

- **GPU:** NVIDIA с 16 ГБ VRAM.
- **CPU:** 8-ядерный процессор.
- **RAM:** 32 ГБ для стабильной работы.
- **Хранилище:** 50 ГБ SSD.

### **Техническая реализация:**

- **Серверная часть:** Модель можно запустить с помощью инструментов, таких как Hugging Face Transformers, обеспечивающих API для взаимодействия.
- **Клиентская часть:** Веб-интерфейс может быть реализован через OpenWebUI, подключающийся к серверу через API.
- **Сеть:** Взаимодействие через локальную сеть с использованием HTTP/HTTPS.
- **План обучения:** Собрать 100-500 пар вопрос-ответ об оздоровительном комплексе, запустить модель локально, настроить через системные сообщения или дообучение, протестировать и развернуть.
